Turn a consolidated green sheet PDF into Excel

Every value is read from its ruled cell in the PDF and written unchanged. Each file is checked before you download, and the Excel file is read back and compared cell by cell.

How it works
  1. Export the Consolidated Green Sheet from the ERP as PDF, for any class. Column counts can differ between classes.
  2. Drop the PDF above. The table grid is rebuilt from the printed lines and each value is placed in its cell.
  3. Review the checks, then download Excel, or a large-print PDF split across A4 sheets you can paste side by side.
